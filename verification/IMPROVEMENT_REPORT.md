## 검증: 원본과 수정본 분리

정확한 프로젝트 버전 Godot `4.7.2.stable.official.ed1daf0bf` 사용. 설치되어 있던 4.6.3 예비 결과와 별도 기록했다.

- 기존 자동 검사: 원본 **986 통과 / 0 실패**, 최종 **986 / 0**.
- 저장 원인 재현: 원본 **1 통과 / 5 실패**. 수정 및 확장 검사 **19 통과 / 0 실패**.
- 게임플레이 회귀: 원본 **4 통과 / 7 실패**, 수정 **11 / 0**.
- 최종 합계: **1,016 검사 통과**. `final-verification.log`.
- 전투: 배경 4 × 단계 3 × 40 = **480회/리비전**, 지표 동일.
- 전쟁: 시드 5 × 240개월 = **1,200개월/리비전**, 지표 동일. 5개 국가 모두 생존, 점령 26–45회.
- 결투: **240회/리비전**, 승패·턴 지표 동일(실행 시간 제외).
- 경제: **1,200개월/리비전**, 지표 동일. 음수 금/식량/병력 0회. 관측 최대 국고 5,674·식량 131,576·도시 병력 12,607. 식량 축적은 후속 균형 검토 대상이며 무한 시간 안정성을 증명하지 않는다.
- 출세: **8개 × 240개월/리비전** 완료. 봉신 6개 재상, 용병 2개 대장 도달. 동료 보호로 RNG 소비와 결과 경로가 달라져 승급 시점은 일부 달라짐. 상세 원본/수정 로그 보관.
- 20년 진행 저장 상태 5개 검증 통과. 데이터/밸런스 상수 변경 없음.

초기 캐시 없는 4.6.3 import의 폰트 오류는 import 완료 후 해소됐다. 가상 디스플레이의 VSync 경고와 Chromium 소프트웨어 렌더러의 ReadPixels 경고는 환경 로그로 남겼다. 최초 브라우저 자동화는 이미 제거된 로딩 DOM을 기다려 시간 초과했고, 제거 여부 판정으로 수정했다. 게임 실패와 구분한다. 최초 career 180초 실행 제한은 검사 도구 제한이었으며 600초 제한으로 다시 끝까지 실행했다.

## 재실행

```sh
# 사용자 저장과 분리된 임시 HOME에서 검사
GODOT=/path/to/godot-4.7.2 tools/verify.sh
GODOT=/path/to/godot-4.7.2 tools/verify.sh --simulations
# 에디터 또는 직접 게임 실행
godot --path .
# 맞는 공식 Web template 설치 후
mkdir -p ../stat-build/web
godot --headless --path . --export-release Web ../stat-build/web/index.html
python3 -m http.server 8765 --directory ../stat-build/web
# 브라우저 http://localhost:8765 (file://로 열지 않음)
```
